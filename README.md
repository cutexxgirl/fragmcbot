## Что это

Telegram-бот для работы с бусти (проверка подписок).
Личный кабинет, тех поддержка, админка, чек подписки в канале, апи (используется в лаунчере), промо-акция, сюда ещё вроде можно сборки загружать, вроде не удаляля код, но надо подключить кнопку в src/bot/keyboards/main.ts.

## Отключённые функции

### Скачивание сборок (для пользователей)

Кнопка «📥 Скачать» убрана из клавиатуры, но код не удалён.

**Чтобы вернуть:**

В `src/bot/keyboards/main.ts` добавь в блок `if (showDownload)`:
```typescript
buttons.unshift(['📥 Скачать']);
```

### Загрузка сборок (для админа)

Есть в админке (кнопка «Сборки»). Работает через `src/modules/builds/manager.ts`.
Обработчики зарегистрированы в `src/bot/index.ts` (строки ~187-188)

## Стэк

- Node.js + TypeScript
- Telegraf (Telegram Bot API)
- Fastify (REST API)
- Prisma + PostgreSQL
- bcrypt (пароли)

## Установка

1. Склонируй репо
2. Скопируй `.env.example` в `.env` и заполни
3. `npm install`
4. `npx prisma migrate dev`
5. `npm run dev`

## Структура

```
src/
├── api/          # REST API (авторизация для лаунчера)
├── bot/          # Telegram бот
│   ├── handlers/ # Обработчики команд и кнопок
│   └── keyboards/# Клавиатура
├── config/       # Конфиги (из .env)
├── database/     # Prisma клиент
├── modules/      # Бизнес-логика (подписки, сборки, промо)
├── services/     # Cron задачи
└── types/        # TypeScript типы
```
