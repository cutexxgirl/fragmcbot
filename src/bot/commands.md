# Команды бота Fragment

## Команды пользователя
- `/start` - Начать работу с ботом

## Админские команды - Подписки
- `/checksubs` - Проверить все активные подписки

## Админские команды - Поддержка

### Управление агентами
- `/добавить_агента <telegram_id>` - Добавить агента поддержки
- `/удалить_агента <telegram_id>` - Удалить агента поддержки
- `/список_агентов` - Показать всех агентов

### Статистика
- `/статистика день|неделю|месяц` - Общая статистика по всем агентам
- `/статистика_агента <telegram_id> день|неделю|месяц` - Статистика конкретного агента
- `/закрыть <ticket_id>` - Закрыть тикет

## Команды агента поддержки (в группе)
- `я` - Принять тикет (ответ на сообщение бота)
- `теперь я` - Перехватить тикет (ответ на сообщение бота)
